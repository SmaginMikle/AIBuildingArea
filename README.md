# AIBuildingArea
**Определение площади застройки по спутниковым снимкам**

Шаги решения задачи:
1. Model.ipynb - для датасета https://project.inria.fr/aerialimagelabeling/ (спутниковые снимки 5000*5000) дообучена модель (**семантическая сегментация, ResNet18**), подобраны параметры с учетом имеющейся видеокарты и технических возможностей. Модель рассчитана и сохранена. Параметры модели на валидационнной выборке: Val IoU: 0.7515 | Val Acc: 0.9619. **В качестве функции потерь использована BCEWithLogitsLoss**, которая включает сумму лосов: 1. Сигмойду к предсказаниям (логитам) и 2. Бинарную кросс-энтропию между преобразованными предсказаниями и целевыми метками. Функция хорошо подходит для задачи бинарной сегментации с одним классом (в нашим случае ищем только дома). При решении задачи сразу обратил внимание на модели семейства U-Net skip-connections. Начал с ResNet34, из-за долгого расчета перешел ResNet18 (и кажется, почти без потери качества). Данные модели хоть и обучались на обычных (а не спутниковых снимках), но уже на ранних слоях умеют распознавать края, углы, простые формы. Эти признаки актуальны и для распознавания домов на спутниковых снимках. 
2. Predict.ipynb - по сохраненной модели получены **предсказания для тестовой выборки** датасета.
3. PredictAny.ipynb - по сохраненной модели получены **предсказания для снимков произвольного размера** (все модели работают с квадратными снимками, реализовано преобразование к размеру модели).
4. DataScale (папка) - **вручную подготовленный датасет с масштабами картинок** (длина и ширина картинки в метрах). Для поготовки датасета були вручную созданы скриншоты google и yandex карт с рассчетом расстояний с использованием линейки на этих же снимках. В дальнейшем дообогащен  снимками исходного датасета (пункт 1)
5. ModelScale.ipynb - первая версия модели регрессии по определению масштаба снимка (ResNet18). Метрики неудовлетворительные, модель сильно переобучается. Train Loss: 353.8576 | Val Loss: 52623.3666
6. ModelScale2.0.ipynb - методом проб и ошибок подобрана модель и ее параметры для определения масштаба снимка (**упрощенная самописная CNN**). Получены предсказания для снимков произвольных размеров. Train Loss: 0.002292 | Val Loss: 0.001730 | MAE total: 185.7 
7. Models (папка) - рассчитанные модели: семантическая сегментация для выделения зданий (house_segmentation_model.pth) и регрессии (CNN) для получения масштаба снимка (best_simple_cnn.pth).
8. App.py - Написано **приложение на Streamlit**, которое загружает произвольный снимок, решает задачу сегментации для определения домов и регрессии для определения масштаба, и выводит результат в виде площади домов и снимков на экран:

9. ModelDetection.ipynb, PredictDetection.ipynb - реализована **альтернативная модель детекции** домов по картинке. Параметры модели на валидационнной выборке: Val IoU: 0.6996 | Val Acc: 0.6018. В обучении использовал исходный (п. 1) датасет с предобработкой: по бинарной маске зданий определил огибающие прямоугольники и их подадил в обучающую и валидационную выборку.

**Выводы:**
   1. В качестве решения задачи определения домов на снимке дообучена модель сегментации с комбинированной функцией лосса. Загружен готовый датасет для обучения, валидации и тестирования. Модель сохранена. Результаты сопоставимы с лидербордом исходного датасета, хотя и не дотягивают до первого места (IoU 0.7515 против 0.8191 у лидера). 
   2. В качестве решения задачи определения масштаба (размера в метрах) снимков был самостоятельно подготовлен датасет, разделенный в будущем на обучающущю и валидационную выборку, написана и обучена упрощенная модель CNN. Модель сохранена.
   3. Для решения задачи по определению площади написано приложение на Streamlit, где последовательно загружается исходный снимок, приводится к квадратному размеру, решается задача сегментации домов для него, решается задача определения масштаба и математически находится доля слоя домов в общей площади снимка.
   4. Решена альтернативная задача детекции.
